1. The Problem LabelFleet Solves

Label Studio Community Edition is a powerful annotation tool, but it has critical gaps when managing teams at scale:

Gap

No Per-User Access Control

Every annotator sees every project. There's no way to restrict who sees what data. This is a compliance and quality nightmare for teams managing sensitive datasets.

Gap

No Automated Data Distribution

Admins must manually create projects, import tasks, and assign annotators. At 50+ annotators, this becomes a full-time job.

Gap

No Workflow Orchestration

Multi-stage pipelines (label → review → expert) require manual coordination. There's no concept of chaining or rejection routing.

Gap

No Built-in Quality Scoring

No gold standard injection, no automatic accuracy scoring, no way to detect underperforming annotators before bad labels reach your model.

LabelFleet solves all of these by wrapping Label Studio CE in a fleet management layer that provisions isolated containers, automates data distribution, orchestrates multi-stage workflows, and scores quality automatically.

3. Core Features Deep Dive

3.1 Per-Annotator Container Isolation

LabelFleet's foundational architecture: each annotator gets their own isolated Label Studio instance with a dedicated PostgreSQL database, unique subdomain, and separate API token. No data leaks between annotators.

Container Startup Flow (8 Steps)

Click Start → Create DB → Deploy Container → LS Boots → Health Check → Register Webhook → Report Token → Auto-Assign

DB provisioning: CREATE DATABASE ls_annotator_{id} on the shared PostgreSQL cluster.
Container deploy: Docker (local) or ECS Fargate Spot (AWS). Traefik labels or ALB listener rules handle routing.
LS bootstrap: Custom entrypoint waits for /health, extracts API token, registers webhook, reports token back to admin.
Auto-assign: Once token is received, autoAssignOnReady() creates the first batch assignment.

Container Status Lifecycle

created → starting → active → stopping → stopped → deleted

3.2 Workflow Chaining

Workflows can be linked into multi-stage annotation pipelines. Each workflow's previousWorkflowId points to its upstream stage. When upstream assignments complete, their annotations are forwarded as Label Studio predictions to the downstream stage.

Source (S3) → Stage 1: Labeler annotations → Stage 2: Reviewer accepted → Stage 3: Expert → Export (S3)

Key mechanics:

  • FIFO ordering — findUnchainedSourceAssignment() picks the oldest unclaimed completed upstream assignment
  • Predictions forwarding — Upstream annotations are fetched via LS API and passed as predictions when importing downstream tasks
  • Race protection — Unique constraint on (workflowId, sourceAssignmentId) prevents two workers from claiming the same source
  • Arbitrary depth — Chain 2, 3, or N stages. No hard limit.

3.3 Rejection Routing

When a reviewer marks a task as "reject" (via a review_decision Choices control in the labeling config), LabelFleet automatically routes the rejected work based on the workflow's rejection policy.

Mode: none

Flag Only

Record the rejection in the audit trail and increment the annotator's rejection count. No further action.

Mode: archive

Archive to S3

Write the rejected task (image key, annotations, reason) to a storage path. Reviewer's annotation details are preserved.

Mode: route_to_workflow

Route to Rework

Create a new chained assignment in the target workflow with only the rejected tasks. Can optionally route back to the original annotator.

Loop prevention: maxReworkIterations stops infinite reject-rework cycles. When exceeded, tasks are escalated (archived) instead of re-routed.

3.4 Gold Standard QA

Known-good labeled tasks are injected into annotation batches at a configurable rate (e.g., 10%). When the annotator completes a gold task, their result is automatically scored against the expected labels.

Scoring Algorithms

TypeAlgorithmScore Range
ClassificationExact match on choices (grouped by from_name)0.0 – 1.0
Bounding BoxesGreedy IoU matching (threshold > 0.1, same label required)0.0 – 1.0 (avg IoU)
Multi-labelPartial credit per group0.0 – 1.0
OtherJSON deep equality (fallback)0.0 or 1.0

Accuracy is tracked per-annotator over time. A configurable threshold (default 70%) flags underperformers.

3.5 Automated Data Distribution

The assignment engine handles the complete data pipeline: listing images from S3/local, excluding already-assigned images, selecting gold tasks, shuffling, creating Label Studio projects, and importing tasks with optional predictions.

Assignment Creation Flow

List S3 images → Exclude assigned → Inject gold tasks → Shuffle → Create LS project → Import tasks

3.6 Real-Time Monitoring

Every annotation event (created, updated, deleted) is recorded with timing data. The monitoring dashboard shows:

  • Annotations per hour (24-hour rolling chart)
  • Per-annotator throughput, avg time, completion rate
  • Time distribution histograms (<10s, 10-30s, 30-60s, 1-2m, 2-5m, >5m)
  • Active assignment progress tracking

3.7 Webhook Processing Pipeline

When Label Studio fires an annotation event, the webhook handler triggers a cascade of side effects:

Webhook received → Store event (idempotent) → Mark task complete → Gold eval? Review detect? → All done? → Export + Chain + Assign

Concurrency safety: Idempotent via unique constraint on (annotatorId, lsAnnotationId, eventType). Atomic completion detection via status guard. All post-completion work is fire-and-forget async.

3.8 Reconciliation Safety Net

A periodic job compares the admin database against Label Studio's actual state. If webhooks were missed (network outage, container restart), reconciliation catches up by updating task counts, marking assignments as complete, and triggering exports. Uses a PostgreSQL advisory lock to prevent concurrent runs across replicas.

6. Local Docker Architecture

LabelFleet runs fully locally via docker compose up. The ORCHESTRATOR_BACKEND=docker env var switches from ECS to Docker mode.

Local (Docker)

  • PostgreSQL 16 on port 5433
  • Traefik reverse proxy on :80/:8080
  • Next.js admin app on :3000 (hot reload)
  • LS containers on fleet-network
  • Traefik labels for subdomain routing
  • Secrets as plaintext env vars
  • Local filesystem for images
  • Docker socket for container management

Production (AWS)

  • RDS PostgreSQL 16 (multi-AZ)
  • ALB with ACM wildcard cert
  • ECS Fargate (admin) + Fargate Spot (LS)
  • VPC private subnets, NAT gateway
  • ALB listener rules for host routing
  • Secrets Manager for sensitive config
  • S3 + CloudFront for images
  • ECS API for container management

Both modes use the same ContainerOrchestrator interface (src/lib/orchestrator/types.ts). The codebase has zero AWS-specific logic in business logic files — all platform differences are encapsulated in the orchestrator implementations.

9. What LabelFleet Enables

With just Label Studio Community Edition and LabelFleet, a team can:

Scale

Manage 5 to 100+ Annotators

Each annotator gets their own isolated workspace. No more shared projects, no data leaks, no "I accidentally labeled someone else's batch."

Automate

Zero-Touch Data Distribution

Point a workflow at an S3 prefix and let LabelFleet batch, shuffle, inject gold tasks, create LS projects, and assign work automatically. When a batch finishes, the next one starts within seconds.

Chain

Multi-Stage QA Pipelines

Build labeler → reviewer → expert chains where upstream annotations become downstream predictions. Rejected work routes automatically to rework queues with loop prevention.

Quality

Automatic Accuracy Scoring

Inject gold standard tasks and score annotators automatically. Detect underperformers before bad labels reach your model. Track accuracy trends over time.

Monitor

Real-Time Visibility

Live dashboards showing annotations per hour, per-annotator throughput, time distributions, completion rates, and rejection rates. Know exactly what's happening across your fleet.

Integrate

Fully Agentic via REST API

28+ endpoints let an AI agent or script provision annotators, start containers, assign work, monitor quality, and export results with zero human interaction.

Cost

~$230/month for 50 Annotators

ECS Fargate Spot keeps costs low. Containers can be scheduled to start/stop on work hours. Local Docker mode is free for development and small teams.

Deploy

Docker Compose or AWS

Clone the repo and docker compose up for local dev. Or deploy to AWS with Terraform for production. Same codebase, same features, pluggable orchestrator.

Bottom line: LabelFleet turns Label Studio CE from a single-user annotation tool into a production-grade fleet management platform with automated pipelines, quality assurance, and real-time observability — without requiring Label Studio Enterprise.
